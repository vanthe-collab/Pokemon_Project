### 🛠 Công nghệ sử dụng
* **Ngôn ngữ:** Kotlin
* **Kiến trúc & Xử lý luồng:** Áp dụng MVVM và Coroutines (sử dụng `awaitAll()` để tối ưu tốc độ tải dữ liệu đồng thời).
* **Mạng (Networking):** Tích hợp RESTful API từ PokeAPI thông qua thư viện Retrofit.
