# 📱 Pokedex Explorer

Ứng dụng tra cứu thông tin chi tiết các loài Pokemon với giao diện bo tròn tối giản.

### 📸 Giao diện ứng dụng
*(Bạn kéo thả 1 tấm ảnh chụp màn hình đẹp nhất của app vào thẳng khung soạn thảo của GitHub, nó sẽ tự tạo link ảnh thay thế cho dòng chữ này)*

### 🛠 Công nghệ sử dụng
* **Ngôn ngữ:** Kotlin
* **Kiến trúc & Xử lý luồng:** Áp dụng MVVM và Coroutines (sử dụng `awaitAll()` để tối ưu tốc độ tải dữ liệu đồng thời).
* **Mạng (Networking):** Tích hợp RESTful API từ PokeAPI thông qua thư viện Retrofit.
